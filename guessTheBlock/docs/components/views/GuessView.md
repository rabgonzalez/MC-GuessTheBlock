# GuessView

## Props

| Prop name     | Description                                                              | Type    | Values | Default |
| ------------- | ------------------------------------------------------------------------ | ------- | ------ | ------- |
| selectedBlock | Block shown in this row                                                  | Block   | -      |         |
| randomBlock   | Block to compare against. Without it the row is neutral (search result). | union   | -      | null    |
| animate       | Play the flip-in reveal animation when mounted                           | boolean | -      | true    |

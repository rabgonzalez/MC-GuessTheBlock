# ResultDialog

## Props

| Prop name | Description                                               | Type     | Values | Default |
| --------- | --------------------------------------------------------- | -------- | ------ | ------- |
| target    | Block the player had to guess                             | Block    | -      |         |
| won       | Whether the player won or gave up                         | boolean  | -      |         |
| attempts  | Number of guesses made                                    | number   | -      |         |
| guesses   | The player's guesses, newest first (without the hint row) | Array    | -      |         |
| mode      | Mode of the finished game                                 | GameMode | -      |         |
